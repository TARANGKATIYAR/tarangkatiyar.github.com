# Portfolio Images Setup

## Required Image Files

To complete your portfolio, please add these image files to your Portfolio folder:

### 1. Profile Image
- **File name:** `profile.jpg`
- **Description:** Your profile/headshot photo
- **Recommended size:** 400x500 pixels or similar ratio
- **Location:** Place directly in the Portfolio folder

### 2. Organization Logos

#### Gurukul School Logo
- **File name:** `images(1).jpeg`
- **Description:** Gurukul The School logo
- **Location:** Place directly in the Portfolio folder

#### Google Cloud Logo
- **File name:** `images.jpeg`
- **Description:** Google Cloud Skills Boost logo
- **Location:** Place directly in the Portfolio folder

#### GoSharpener Logo
- **File name:** `unnamed.png`
- **Description:** GoSharpener organization logo
- **Location:** Place directly in the Portfolio folder

## Folder Structure
```
Portfolio/
├── index-new.html
├── style-clean.css
├── script-new.js
├── profile.jpg          ← Your profile photo
├── images(1).jpeg       ← Gurukul logo
├── images.jpeg          ← Google Cloud logo
└── unnamed.png          ← GoSharpener logo
```

## Image Requirements
- **Profile photo:** Should be professional, clear, and high-quality
- **Organization logos:** Should be official logos, preferably square format
- **File formats:** JPG, JPEG, PNG are all supported
- **Size:** Images will be automatically resized by CSS

## Fallback System
If any image fails to load, the portfolio will automatically show:
- A professional avatar with your initial "T" for profile
- Emoji icons for organization logos (🎓 ☁️ 🚀)

## How to Add Images
1. Save your images with the exact file names listed above
2. Place them in the same folder as your HTML file
3. Refresh your browser to see the images

Your portfolio will look much more professional with these images added!
